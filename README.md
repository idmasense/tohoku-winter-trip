# ❄️ 日本東北 7 天 6 夜雪季夢幻之旅（12/17 - 12/23）

互動式旅遊行程與旅費累積計算網頁（日系可愛雪國手帳風）。

## 🌐 GitHub Pages 線上網址

- **部署網址**：https://idmasense.github.io/tohoku-winter-trip/

## ✨ 功能特色

- **單日手帳頁籤（Day 1 ～ Day 7）**：每天獨立一頁，含專屬可愛 SVG 插圖、各站交通時間、景點介紹、雪季防寒提醒與 Google 地圖搜尋定位連結。
- **景點原地核選與記帳**：每個行程站點底下直接顯示預估項目，可直接勾選「已支出」、修改實際金額或展開表單「＋ 記一筆費用」。
- **最後一頁「總結・財務計算」**：即時匯率換算（JPY ⇄ TWD）、日幣現鈔／Suica／信用卡累積統計、每日與分類進度條、CSV 匯出、票券裝備檢查表與名店攻略，資料自動保存於瀏覽器 `localStorage`。
- **單一可攜版**：亦附有 `tohoku-winter-trip-standalone.html` 可離線單檔分享。
